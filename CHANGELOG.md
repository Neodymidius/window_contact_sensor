# Changelog

## 0.1.0 — 2026-10-30

First public firmware source package and experimental binary release. Includes
IAS contact reporting, LiPo voltage/percentage, EM2 power policy, host tests,
portable SDK setup, build instructions and checksummed HEX/S37 packaging.
Existing FreeCAD enclosure files and the original MIT license are preserved.

See [RELEASE_NOTES.md](RELEASE_NOTES.md) for validation and limitations.
